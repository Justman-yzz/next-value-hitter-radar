분석 방법

신호는 이렇게 만들고, 이렇게 검증합니다

세부능력 점수 (v1)

ISO·BB%·K%의 같은 리그·시즌 내 백분위를 45/30/25로 가중합니다. 다만 이 점수는 OPS와 상관이 약 0.8이라, 현재 성적을 다시 재는 것에 가깝습니다.

독립 신호 z (v2)

v1에서 OPS로 설명되는 부분을 회귀로 빼고 남은 잔차를 표준화합니다. OPS와의 상관이 0인 것은 계산상 당연할 뿐, 예측력의 증거가 아닙니다.

백테스트

앞 시즌 정보만으로 만든 신호가 다음 시즌 OPS 백분위 변화를, OPS·나이만 쓴 기준 모형보다 더 설명하는지 순열검정으로 확인합니다. 성공 확률은 표시하지 않습니다.

KBO CSV 형식

내 KBO 파일로 분석하려면

  1. 필수 열: season, league, player_name, team, PA, BB, SO (league = KBO 또는 FUTURES)
  2. 점수 계산에 필요: OBP(또는 H, AB, HBP, SF)와 AVG·SLG(또는 AB, H, 2B, 3B, HR). 권장 열: player_id, age
  3. 헤더 예시: data/schema.csv · KBO 모드 열기
