과제 1 · 핵심 그래프 한 장

OPS는 낮은데 세부 지표가 앞선 타자는 누구인가?

해당 시즌 타자 전원을 한 장에 올렸습니다. 가로는 현재 성적(OPS 백분위), 세로는 그 OPS 수준에서 기대되는 것보다 장타·선구·컨택 지표가 얼마나 좋은지(독립 신호 z)입니다. 왼쪽 위 영역의 선수가 "현재 성적에 가려진 신호" 후보입니다.

스카우팅 산점도

원석 신호 · z ≥ 1, OPS 백분위 < 45, 100타석+100타석 이상30~99타석 · 판정 제외선택 선수점 크기 = 타석 수

점을 누르거나 탭하면 오른쪽에 상세 지표가 나옵니다. 차트에 초점을 두고 ← → 키로 선수를 옮길 수 있습니다. z가 ±3을 넘는 선수는 가장자리에 표시됩니다.

읽는 법과 한계

이 그래프가 말하는 것과 말하지 않는 것

축과 점의 정의

  1. 비교 집단: 같은 리그·같은 시즌의 30타석 이상 선수. MLB와 KBO는 따로 계산합니다.
  2. 세부능력 점수(v1) = ISO 백분위×0.45 + BB% 백분위×0.30 + (100−K% 백분위)×0.25
  3. 독립 신호 z(v2) = v1을 OPS 백분위에 선형회귀한 잔차를 표준화한 값
  4. 원석 신호 = z ≥ 1.0, OPS 백분위 < 45, 100타석 이상. KBO 탐색 때 정한 기준이며, MLB 데이터를 본 뒤 바꾸지 않았습니다.

알려진 문제 · 검증 상태

  • —
  • v2의 OPS 상관이 0인 것은 회귀 잔차의 수학적 성질입니다. 그것만으로는 예측력의 증거가 아닙니다.
  • 모델 상태: Experimental Scouting Model (v0.1.0). 탐색적 검증만 거쳤고, 독립 검증은 하지 않았습니다.
  • —

한계

  • 점수는 탐색용 지표입니다. 다음 시즌 성공 확률이 아닙니다.
  • 가중치(45/30/25)는 가설 값이며 추정한 값이 아닙니다.
  • z가 높은 선수는 같은 OPS 대비 BABIP이 낮은 경우가 많습니다. 운인지 타구 질 문제인지는 구분할 수 없습니다.
  • 표본 참고 지수는 지표별 PA/(PA+M)의 평균인 프로젝트 내부 근사 지표입니다. M(K% 60 PA, BB% 120 PA, ISO 160 AB)은 FanGraphs 안정화 참고 기준이지만 척도가 다르고, ISO에도 PA를 씁니다. 높음·보통·낮음 구간은 임의 분류이며 검증된 신뢰도나 성공 확률이 아닙니다.
  • MLB의 PA에는 포수 타격방해(연 0~3회)가 빠져 있습니다. 구장·수비 위치·부상은 보정하지 않았습니다.
